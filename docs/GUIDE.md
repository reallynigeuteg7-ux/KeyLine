# KeyLine

Минималистичный тренажёр слепой печати для Windows x64. C# 12, .NET 8, Windows Forms. Чёрно-белый интерфейс с оттенками серого, геометрическая K в скруглённой рамке. Логотип в интерфейсе, значок exe и ярлыка — белые, на прозрачном фоне. Значок ярлыка занимает почти весь холст, чтобы отображаться крупнее.

Шрифт интерфейса и упражнений — Montserrat. Обычное и жирное начертания включены в папку `Assets/Fonts` и загружаются локально без установки в Windows. Источник: https://github.com/JulietaUla/Montserrat . Лицензия SIL Open Font License приложена в `Assets/Fonts/OFL.txt`.

## Запуск готовой программы

Откройте `Keyline.exe` в соседней папке `Keyline-Windows`. Отдельная установка .NET не требуется: среда выполнения включена в поставку. При переносе копируйте всю папку `Keyline-Windows`, а не один exe.

Архив `Keyline-Windows.zip` можно распаковать в удобную папку на диске D: и запустить программу оттуда. Приложение не требует прав администратора и не подключается к интернету.

## Тренировка

1. Выберите RU или EN и длительность 30, 60 или 120 секунд.
2. Переключите системную раскладку на язык упражнения.
3. Начните печатать показанный текст: отсчёт запускается первым символом.
4. Исправляйте опечатки клавишей Backspace. Вставка из буфера не поддерживается.
5. По истечении времени результат сохранится. Enter начинает новую тренировку.

Escape и кнопка «Новая сессия» сбрасывают текущую попытку. Незавершённые попытки в историю не попадают. Настройки и статистика доступны до начала или после завершения сессии. Таймер продолжает идти при переключении на другое окно.

Текст перелистывается автоматически. Белым отмечены введённые символы; ошибки выделены серой подложкой и подчёркиванием. Белая линия показывает позицию ввода. Подсказка основного ряда помогает ориентироваться по исходному положению рук.

## Подсчёт результатов

- WPM = количество верных символов в текущем тексте / 5 / прошедшие минуты. Пробелы и пунктуация учитываются. Первую секунду показывается 0, чтобы избежать скачка при старте.
- Точность = доля верных нажатий среди всех введённых печатных символов. Исправленная ошибка остаётся в этой метрике.
- Ошибки = суммарное количество неверных нажатий. Backspace не считается печатным символом.
- Результат после истечения лимита рассчитывается ровно по выбранной длительности.

Раздел статистики показывает личный рекорд, средние показатели, график последних 12 тренировок и последние четыре результата. До 200 результатов хранятся в `Data/history.json` рядом с exe. Папке программы нужен доступ на запись. При ошибке сохранения приложение показывает сообщение в интерфейсе.

## Исходный код

- `Program.cs` — точка входа.
- `Session.cs` — состояние тренировки, тексты, формулы и сохранение истории.
- `TrainerForm.cs` — окно, отрисовка интерфейса и обработка ввода.
- `Assets/logo-white.png` — белый логотип для интерфейса, прозрачный PNG.
- `Assets/logo-black.png` — сохранённая чёрная версия логотипа, прозрачный PNG.
- `Assets/logo-white-large.png` — белый вариант с сокращёнными полями для ярлыка, прозрачный PNG.
- `Assets/keyline-white-large.ico` — белый увеличенный значок exe и ярлыка в размерах 16–256 px.
- `Assets/keyline.ico` — копия белого значка для совместимости.
- `Assets/keyline-window.ico` — белый значок окна на тёмной панели.
- `build.ps1` — сборка готовой версии для Windows x64.

Откройте `Keyline.csproj` в Visual Studio 2022 с компонентом разработки классических приложений .NET. Либо запустите `build.ps1` в PowerShell. Скрипт использует SDK из `D:\Codex\tools\dotnet`, направляет временные файлы и кеши на D: и создаёт папку `Keyline-Windows` рядом с исходниками.

## Ограничения

Это локальный тренажёр без аккаунтов, облачной синхронизации и установщика. Интерфейс отрисовывается вручную; полноценная поддержка экранных дикторов пока не реализована. Результаты разных языков и длительностей входят в общую статистику.
