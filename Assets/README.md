# Логотип KeyLine

Основа — предоставленное пользователем изображение геометрической K в скруглённой рамке. Для значка используется эмблема без мелкой подписи; в шапке программы рядом с ней отображается белое название KeyLine с отступом 10 пикселей от знака.

Обработка: встроенный imagegen, затем экспорт PNG и ICO с общей маской прозрачности. Финальный запрос к imagegen: «Сохранить форму рамки и геометрической K с отдельной вертикальной стойкой. Удалить подпись keyline. Сделать знак чёрным, фон и внутренние просветы полностью прозрачными. Квадратный холст, ровные края, без теней и текстуры». Белый вариант использует ту же маску прозрачности.

`logo-black.png` и `logo-white.png` — одинаковые по форме PNG с альфа-каналом. Фон не содержит цветной подложки. ICO созданы из этих PNG для интеграции с Windows.

Текущий ярлык и exe используют белый `keyline-white-large.ico`. Для него прозрачные поля исходного PNG сокращены: знак занимает около 98% ширины холста. Экспортированный PNG для этого варианта — `logo-white-large.png`. Размеры других значков рабочего стола не меняются.
